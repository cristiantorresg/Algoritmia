
ALGORITMOS EN PSEINT


-Parqueadero.psc
Calcula cuánto debe pagar un vehículo por el tiempo de estacionamiento.

Pide el tipo de vehículo (1 para carro, 2 para moto), los minutos que estuvo y si tiene factura de compra (S/N).

Los primeros 15 minutos son gratis.

Cobra por hora o fracción: $4000 para carros y $2000 para motos, con un cobro máximo de $30000.

Si tiene factura, le hace un descuento del 50% al valor final.

-Semaforo.psc
Revisa el estado del inventario según la cantidad de productos.

Pide cuántas unidades hay disponibles.

Muestra "Rojo: agotado" si hay 0.

Muestra "Amarillo: pedir" si hay entre 1 y 10.

Muestra "Verde: todo bien" si hay más de 10.

Si el número es negativo, marca error.

-ValidarEdad.psc
Revisa si una persona es mayor o menor de edad.

Pide la edad.

Si la edad es menor a 0 o mayor a 120, marca error.

Si tiene 18 o más, dice que es mayor de edad; si tiene menos, dice que es menor de edad.

-ValidarRegistro.psc
Comprueba que los datos para crear una cuenta sean válidos.

Pide un nombre de usuario y una contraseña.

Verifica que el usuario no quede en blanco y que la contraseña tenga mínimo 8 caracteres.

Si cumple todo, dice "Registro exitoso", si no, "Registro invalido".

-Bisiesto.psc
Indica si un año es bisiesto o no.

Pide escribir un año.

Revisa si el año es divisible entre 4 (pero no entre 100) o si es divisible entre 400 para confirmar si es bisiesto.
